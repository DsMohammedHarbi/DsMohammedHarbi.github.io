Olist Delivery Performance

An analysis of ~96,000 orders from a Brazilian e-commerce marketplace: how often orders arrive late, why, and what it costs in customer satisfaction.

Download Power BI file PDF version
View full size ↗ View full size ↗ View full size ↗

Key findings

8.1%of orders arrive late

And late orders are rated 2.6 / 5, compared with 4.3 for on-time orders.

25 vs 7days in shipping

Shipping, not sellers, drives most of the delay — and cross-state orders are late about 50% more often.

38%with slow sellers

Orders held 11+ days by the seller are late 38% of the time, vs under 6% when shipped within a day.

Recommendations

Add carrier capacity before peak seasons, and review carriers serving distant regions.

Set a maximum prep time for sellers, and follow up with those who exceed it.

How it was built · for the technical details
Data prep · Power Query
  • 5 tables, delivered orders only
  • Prep Days, Shipping Days and Is Late columns
  • ~1,350 orders with impossible timestamps: blanked the broken value instead of deleting the order
  • Removed unused columns, cutting the file size by about a third
Data model
  • Star schema with orders as the fact table
  • Single-direction filters by default
  • Two-way filter between orders and order_items so seller filters reach order metrics
DAX
  • Late rate, averages and rating measures
  • Rating averaged per order, since some orders have several reviews
  • Prep-time buckets with a custom sort order
Avg Review Score =
AVERAGEX(orders,
  CALCULATE(AVERAGE(reviews[review_score])))
Design
  • Custom theme and a fixed layout grid
  • One colour per meaning: red for late, grey for context
  • Chart titles state the finding
  • Synced filters and page navigation

Data: Olist Brazilian E-Commerce (Kaggle), Jan 2017 – Aug 2018 · Project files on GitHub
